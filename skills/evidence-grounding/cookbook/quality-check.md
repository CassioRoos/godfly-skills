# Evidence Quality Check

## Before Presenting Any Evidence

Run through this checklist. If evidence fails any critical check, do not present it as strong evidence.

## The Checklist

### Critical Checks (must pass)

| Check | Question | Fail = |
|-------|----------|--------|
| **Relevance** | Does this evidence directly apply to this specific decision? | Discard |
| **Specificity** | Can you point to exact code, data, or source? | Downgrade to Tier D |
| **Verifiability** | Can the user check this themselves? | Flag as unverifiable |

### Quality Checks (affect tier rating)

| Check | Question | Impact |
|-------|----------|--------|
| **Recency** | Is this from the last 2-3 years? | Old evidence drops one tier |
| **Scale match** | Same order of magnitude as our system? | Mismatched scale drops one tier |
| **Cherry-picking** | Is there counter-evidence you're ignoring? | Must present counter-evidence |
| **Causation** | Did the evidence cause the outcome, or just correlate? | Flag as correlational |
| **Survivorship** | Are you only seeing successes, not failures? | Search for failure cases too |

## Counter-Evidence Obligation

Before presenting evidence FOR your position, actively search for evidence AGAINST it:

1. Search for teams that succeeded with the approach you're challenging
2. Search for teams that failed with the approach you're recommending
3. If counter-evidence exists, present it alongside your evidence

This builds credibility and prevents blind spots. If you can't find counter-evidence after a genuine search, say so -- that strengthens your position.

## Confidence Levels

Based on evidence quality, assign confidence:

| Confidence | Criteria |
|-----------|----------|
| **High** | Multiple Tier A/B sources, consistent findings, directly applicable |
| **Medium** | One strong source or multiple moderate sources, some context differences |
| **Low** | Tier C/D evidence only, significant context gaps, or conflicting evidence |

## Red Flags in Your Own Reasoning

Watch for these in your own analysis:

| Red flag | What's happening | Fix |
|----------|-----------------|-----|
| "Obviously..." | You're asserting without evidence | Find the evidence or drop the claim |
| "In general..." | You're generalizing from limited data | Specify the context |
| "Best practice is..." | You're appealing to convention | Find the rationale behind the practice |
| "Everyone knows..." | You're assuming shared knowledge | Cite the source |
| No counter-evidence found | You might not be looking hard enough | Try searching for the opposite conclusion |
